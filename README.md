# HERV-AI-CONTROLS-COMPUTER-FOR-YOU
Hervé listens orders & executes them on the computer. Aged people can speak, but cannot use a computer. Here it is. Hervé sees the screen, and clicks, double-click, scroll, fetches. He is a real human helping grandpa and grandma. Limitations : the whole project stopped due to ChatGPT limitations, these tasks do not fit with a LLM, based on text input and output.

Why this way ? Why not a intern action managing, like communicating directly with softwares (using API, or libraries) :
This offers a full control that doesn't require any update. As the user has full access to the computer, ChatGPT has it too.

Now, when ChatGPT or his friends will be more competant, this code will be useful.

If one day this is useful, may it be free, as the original code was.
